# C.04.6 and record-299 expectation changes

The C.04.6 corrections change the prescribed pairing for 200 team fixtures:
184 through pairing-number ordering and 16 through standings-score colour
allocation in accelerated events. The corpus `valid` flags carry those
feature-owned expectation changes. Incompletable rounds retain the checker's
existing article-3.3.3 fallback and remain valid.

The overlay removes expectations that those corrected verdicts make obsolete.
It also removes the record-299 reader-refusal groups after this branch
changes those 54 fixtures' `valid` flags. Their TRF text is unchanged: 29 carry
a type with round `000` and a named competitor and are intentionally refused
with status 419; 25 team files use a player number where a team pairing number
is required and are intentionally refused with status 502. Marking those input
shapes invalid makes the refusal the expected verdict, so they no longer belong
in the known-failure set. Focused tests keep both refusals and the accepted
neighboring record-299 forms explicit.

The overlay also reclassifies the remaining pairing/standings disagreements
observed by this branch.

The exact current counts are derived from `corpus.jsonl.gz` and the composed
known-failure data rather than duplicated in prose.
